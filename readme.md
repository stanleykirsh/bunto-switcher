# Bunto Switcher

Автоматический переключатель раскладок клавиатуры для Linux. \
Исправляет текст, набранный в неправильной раскладке, прямо в процессе печати.

![Markdown image](demo_switch.gif)

## Возможности

- **Автопереключение** — исправление происходит в реальном времени при обнаружении ввода на не правильном языке

- **Ручное переключение** — исправление последнего набранного текста по нажатию `Pause/Break`

- **Исправление двух заглавных** — автоматическая коррекция `ПРивет` → `Привет`

- **Системный трей** — индикатор в панели GNOME через AppIndicator

- **Автозапуск** — автоматический старт при входе в систему

## Требования

- Linux + GNOME

- Python 3.11+

- Fedora / RHEL-based (автоматическая установка зависимостей через dnf)

## Установка

```bash
sudo ./install
```

Скрипт:

- копирует файлы в /usr/share/bunto

- добавляет приложение в автозапуск

- настраивает sudo-доступ (необходим для evdev)

- устанавливает зависимости (python3-evdev, gnome-shell-extension-appindicator)

## Удаление

```bash
sudo ./uninstall
```

## Принцип работы 

1. Приложение перехватывает события клавиатуры через evdev

2. Последнее набираемое слово в закодированном (но не зашифрованном) виде накапливается в буфер

3. На основе n-грамм определяется наиболее вероятный язык текущего буфера

4. Раскладка в системе автоматически переключается через D-Bus / gsettings

5. Текст из буфера перебивается в правильной раскладке
